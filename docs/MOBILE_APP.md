# تطبيق الموبايل (PWA + APK)

نسخة موبايل مبسّطة بتفتح على المسار `/m` من نفس الموقع: مهام، مشاريع، عملاء، تنبيهات، وزرّ "+" للإضافة السريعة. بتستخدم نفس الدخول والـ API والصلاحيات واللغتين. أونلاين فقط.

## التثبيت على الموبايل
- **أندرويد (Chrome):** افتح `https://nexus.creativecode.com.eg/m` ← قائمة الأفاتار ← "تثبيت التطبيق" (أو قائمة Chrome ← "Install app").
- **آيفون (Safari):** افتح نفس الرابط ← مشاركة ← "إضافة إلى الشاشة الرئيسية".
- التطبيق بيفتح على `/m`، وجلسة الدخول بتفضل 7 أيام وبتتجدد مع الاستخدام.

## ملف APK (بدون متجر)
الـ APK هو غلاف (Trusted Web Activity) حوالين نفس الـ PWA، فمفيش كود زيادة.

1. انشر النسخة على السيرفر بالأمر المعتاد (`git pull && npm run build && pm2 restart nexus-app`).
2. افتح <https://www.pwabuilder.com> وحط رابط الموقع `https://nexus.creativecode.com.eg/m`.
3. اختار **Android** ← **Generate package** (نوع الملف: APK للتثبيت اليدوي). ممكن تسيب خيارات التوقيع على الافتراضي، واحفظ ملف المفتاح (keystore) وكلمة السر في مكان آمن، لأنك هتحتاجهم لأي تحديث لاحق.
4. هتنزّل مجلد فيه الـ APK وملف `assetlinks.json`. حط الملف في المشروع بالمسار:
   `client/public/.well-known/assetlinks.json` ثم ابني وانشر. السيرفر بيقدّمه على `/.well-known/assetlinks.json` (راجع `serveStatic` في `server/vite.ts`). من غيره التطبيق بيفتح بشريط عنوان المتصفح بدل ما يكون ملء الشاشة.
5. ثبّت الـ APK على الأجهزة يدوياً (السماح بالتثبيت من مصدر غير معروف).

بديل: `bubblewrap` على جهازك (يحتاج JDK و Android SDK).

## ملفات PWA
- `client/public/manifest.webmanifest`: الاسم، `start_url: /m`، الألوان، الأيقونات.
- `client/public/sw.js`: بيحفظ ملفات التطبيق نفسها فقط (scripts/styles/fonts/icons). طلبات `/api` دايماً على الشبكة. من غير إنترنت بيظهر "لا يوجد اتصال".
- `client/public/icons/*`: أيقونة مؤقتة (رمز المبنى باللون الأساسي). لما يكون عندك لوجو، بدّل `icon.svg` وملفات PNG نفس الأسماء والأحجام (192، 512، maskable 512، apple-touch 180).
- التسجيل في `client/src/main.tsx` (في الإنتاج بس).

## الكود
`client/src/mobile/`: `MobileApp.tsx` (الشريط السفلي والتنقل)، شاشة لكل قسم، `QuickAdd.tsx`، `TaskSheet.tsx`، و`logic.ts` (دوال نقية بتتختبر: تجميع المهام وبناء طلبات الإضافة).
لإضافة قسم جديد: شاشة جديدة + سطر في مصفوفة `TABS` في `MobileApp.tsx` + مفاتيح الترجمة `m.*` في `lib/i18n.ts`.

## الإشعارات
النسخة الحالية: تبويب "التنبيهات" بعدّاد غير المقروء (تحديث كل 30 ثانية). إشعارات الدفع (Web Push) مرحلة لاحقة وتحتاج مكتبة `web-push` ومفاتيح VAPID وتخزين اشتراكات، فتحتاج `npm ci` مرة واحدة على السيرفر.
